    How Momentum works

    Built for the Teens Hack Houston (Triple H) Hackathon 2026, productivity theme, technical track. It fuses three ideas the research phase found separately across the field — backward deadline planning, energy-matched re-ranking, and evidence-verified capture — into one engine, deployed as a single offline file.

    The scheduler is deterministic: tasks sorted by deadline, placed backward into free blocks with pace-adjusted durations; same input, same plan — testable by design. The capture layer runs a rule-based extractor offline (weekday/time regexes, subject keywords, duration parsing) and an optional model path that must cite an exact substring of your text or the item is dropped. The honesty loop tunes per-category pace multipliers from your actual completion times.

    Privacy: everything lives in this browser's localStorage — no account, no server, no tracking; the optional key never leaves the page. Accessibility: full keyboard navigation, visible focus rings, AA-contrast in both themes, 44px touch targets, reduced-motion respected.
